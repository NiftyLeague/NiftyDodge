Auto Relaunch v1.0.4
--------------------
- Import and place the AutoRelaunch.dll under any "Editor" folder.
- You're all set! This tool will automatically relaunch your scene after the script compilation is complete, given the editor is in Play mode when compilation starts.

You can enable/disable this feature and set a delay (in seconds) for the relaunch by opening the "Tools/Auto Relaunch Settings" menu.

Enjoy! And feel free to contact me with any issues or feedback.
